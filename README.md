# Astronomy MPL Style

My personal `matplotlib` styling sheet. It has been hosted publically on GitHub for ease of use elsewhere. It follows my personal preferences and typical styling guides in astronomy (like inside ticks, ticks on both sides, etc.).

___

## Usage

Using the stylesheet is easy without downloading it, thanks to GitHub:
```py
import matplotlib.pyplot as plt

# Load the remote stylesheet.
plt.style.use([
    'https://raw.githubusercontent.com/RandomKiddo/astro-mpl-style/refs/heads/master/astronomy.mplstyle'
])
```

And then you're done!
